---
name: procedural-checks
description: Use this skill to ensure adherence to procedural rules and conventions during software development tasks.
---
- **Review House Rules**: Familiarize yourself with the house rules relevant to the task at hand.
- **Check Test Modifications**: Ensure that no original test files are modified; create new test files if necessary.
- **Verify Type Annotations**: Confirm that all public functions have type annotations for parameters and return values.
- **Document Changes**: Record all changes in the CHANGELOG.md under the '## Unreleased' section with appropriate bullet points.
- **Regression Testing**: Create a regression test file for each bug fixed, ensuring it contains at least three test functions.
- **Output Format Compliance**: Validate that all output formats match the specified requirements (e.g., JSON structure, CSV headers).
- **Data Cleaning Steps**: Implement necessary data cleaning steps before processing data (e.g., removing duplicates, handling missing values).
- **Run Tests**: Execute the test suite after making changes to confirm that all tests pass successfully.
- **Review Error Handling**: Ensure that error handling is robust and that exceptions are logged correctly.
