---
name: output-formatting
description: Use this skill to ensure that output files conform to specified formats and conventions.
---
- **Define Output Structure**: Clearly outline the required structure of output files (e.g., JSON, CSV).
- **Standardize Timestamps**: Ensure all timestamps are formatted in UTC and follow the specified format (e.g., YYYY-MM-DDTHH:MM:SSZ).
- **Canonical Spelling**: Use canonical spelling for categorical data (e.g., regions) to maintain consistency.
- **Data Type Validation**: Confirm that numeric values are in the correct format (e.g., integers for cents).
- **Include Metadata**: Add necessary metadata to output files, such as row counts and source information.
- **Error Handling in Outputs**: Implement checks to handle potential errors in output generation (e.g., serialization issues).
- **Test Output Files**: Validate output files against expected formats and structures before final submission.
