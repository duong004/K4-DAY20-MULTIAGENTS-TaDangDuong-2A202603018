---
name: regression-testing
description: Use this skill to ensure that regression tests are properly implemented and executed after changes.
---
- **Identify Fixed Bugs**: Document all bugs that have been fixed and require regression tests.
- **Create Test Functions**: For each fixed bug, create a dedicated test function that verifies the fix.
- **Organize Tests**: Place regression tests in a designated test file (e.g., tests/test_regressions.py).
- **Run Regression Tests**: Execute the regression test suite to ensure all tests pass after changes are made.
- **Review Test Coverage**: Check that regression tests cover all relevant scenarios related to the fixed bugs.
- **Maintain Test Documentation**: Update any relevant documentation to reflect the new tests and their purposes.
- **Monitor Test Results**: Keep track of test results and address any failures promptly to maintain code quality.
